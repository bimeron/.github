# bimeron/.github

Organization-wide files for [Bimeron Network](https://github.com/bimeron).

- [`profile/README.md`](profile/README.md) is shown on the organization's GitHub page.
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md),
  [`SUPPORT.md`](SUPPORT.md) and the issue and pull request templates in
  [`.github/`](.github) are used by every repository in the organization that has no file of its
  own.
