# Getting support

## Documentation first

- [Bimeron Desktop](https://github.com/bimeron/bimeron-desktop#readme): installation, upgrades
  and features of the Windows and Linux app.
- [Bimeron Core](https://github.com/bimeron/bimeron-core#readme): profiles, supported upstreams,
  platform status and integration guides. The full list is in its `docs/` folder.

Documentation on the default branch can describe changes that are not released yet. For a
downloaded package, open the README at that release's tag.

## Questions and problems

Open an issue in the repository of the project you use. Include the version, your operating
system and the steps that lead to the problem.

Bimeron does not provide VPN servers or access profiles. Ask your server provider about problems
with a particular server or subscription.

## Security issues

Do not report vulnerabilities in public issues. Follow the [security policy](SECURITY.md).
